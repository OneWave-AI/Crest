# Security Policy

## Supported Versions

The current release line receives security updates. Older versions are not
patched once a newer release is available.

| Version | Status            |
| ------- | ----------------- |
| 2.3.x   | Active support    |
| < 2.3   | No longer updated |

## Reporting a Vulnerability

Please report security issues privately so they can be addressed before
public disclosure.

- Email: **security@onewave-ai.com**
- Or open a [private GitHub security advisory](https://github.com/OneWave-AI/Crest/security/advisories/new)

Please include:

- A description of the issue and the impact
- Steps to reproduce (or a minimal proof of concept)
- The version of Crest you tested against
- Your name / handle if you'd like to be credited

We aim to acknowledge reports within **3 business days** and to ship a fix
or mitigation within **30 days** for confirmed issues. Coordinated
disclosure timelines can be discussed for more complex cases.

## Scope

In scope:

- The Crest desktop application (this repository)
- The release artifacts published on GitHub Releases
- The auto-update flow

Out of scope:

- Vulnerabilities in upstream dependencies (please report those upstream;
  we'll track and ship the fix)
- Issues that require local administrator access to exploit
- Social-engineering reports

## Safe Harbor

We will not pursue legal action against researchers who:

- Make a good-faith effort to avoid privacy violations, data destruction,
  or service interruption
- Report findings privately through the channels above
- Give us a reasonable window to respond before public disclosure
